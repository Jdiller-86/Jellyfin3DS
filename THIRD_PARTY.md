# Third-party software

PocketJS is an MIT-licensed pinned Git submodule at `vendor/pocketjs`; its licenses cover its runtime, native dependencies, and fonts.

`host/native-media.ts` adapts `host/native-media.ts` from https://github.com/pocket-stack/pocket-youtube (MIT).
The original license is reproduced in `LICENSES/pocket-youtube.txt`. Adaptations add Jellyfin authentication and silent-source handling.

Jellyfin3DS is an independent, unofficial client; it is not endorsed by Jellyfin or Nintendo.
