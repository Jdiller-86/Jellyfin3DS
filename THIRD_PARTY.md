# Third-party software

Jellyfin3DS is independent and unofficial. It is not endorsed by Jellyfin or Nintendo.

- [PocketJS](https://github.com/pocket-stack/pocketjs) is pinned at `vendor/pocketjs` and is MIT licensed. Its repository contains the runtime and font license texts.
- [bogocat/jellyfin-3ds](https://github.com/bogocat/jellyfin-3ds) is pinned at `vendor/jellyfin-3ds` and is GPL-3.0 licensed. Jellyfin3DS stages its FFmpeg demux, MVD decoder, audio, texture, logging, and cJSON sources for the native build, with authentication, TLS, and PocketJS texture adaptations generated by `scripts/native-host.ts`.
- cJSON is MIT licensed; its notice is present in the pinned source file and reference repository.
- FFmpeg is built from the exact ThirdTube fork revision pinned by `vendor/jellyfin-3ds/lib/ffmpeg/build-ffmpeg.sh`. Its enabled configuration uses the libraries needed for MPEG-TS, H.264, AAC, and resampling.
- libcurl, mbedTLS, zlib, devkitARM, libctru, citro2d, and citro3d are supplied by the pinned devkitPro toolchain and retain their own licenses.

This combined program is distributed under GPL-3.0. The complete GPL text is at `vendor/jellyfin-3ds/LICENSE` and is copied into install artifacts as `licenses/GPL-3.0.txt`.
